# 4D Vanning Optimization System (時間軸適応型 バンニング最適化システム)

本プロジェクトは、コンテナの積載効率（充填率）を最大化するための**「4D（3D空間 + 時間軸）最適化システム」**です。
従来の静的な3Dパズル（空間のみの最適化）に「時間軸（Time Axis）」の概念を加え、未来の荷物を前倒し（Pull）したり、現在の荷物を繰り越し（Push）することで、コンテナの充填率を限界まで高めることを目的としています。

## 背景と課題（いすゞロジスティクス様のケース）

物流現場において、以下の厳しい制約が存在します。
*   **【KPI】充填率80%の壁**: コンテナの積載率（体積・重量）が80%未満の場合は赤字となる。
*   **納期絶対**: 船での輸送に1〜2ヶ月かかるため、現地の工場への納期は絶対条件。
*   **保管期限の限界**: 木箱などの梱包材には耐久性（防錆等）の限界があり、倉庫内での保管・前倒し待機は「最大3週間」。
*   **倉庫キャパシティ**: 保留プール（繰り越し荷物）を無制限に置くことはできない。

## システムの特長（Paradigm Shift）

これらの課題を解決するため、本システムは以下の機能を備えています。

1.  **時間軸操作アルゴリズム（Pull & Push）**
    *   **前倒し（Pull）**: コンテナ充填率が80%未満の場合、次週以降のリストから「前倒し可能」な荷物を引っ張ってきて80%以上を達成します。
    *   **繰り越し（Push / 待機）**: 納期に余裕がある場合、無理に出荷せず「保留プール」に入れ、次回の荷物と合流させて再計算し、高充填率を目指します。
2.  **ステータスの可視化**
    *   🟢 **正常クリア**: 充填率80%以上
    *   🟡 **前倒し補填 / 繰り越し合流**: 時間軸操作によって赤字を回避したコンテナ
    *   🔴 **納期優先の赤字出荷**: 前倒しも繰り越しもできず、納期限界のため赤字覚悟で強制出荷するコンテナ
3.  **高速な3Dパッキング計算**
    *   Numbaを活用した高速な3Dパッキング処理（メタヒューリスティクス / 遺伝的アルゴリズム）により、膨大な組み合わせパターンから最適解を導出します。

## 技術スタック

*   **バックエンド**: Python 3.x, Flask
*   **最適化アルゴリズム**: Numba, 独自メタヒューリスティクス・エンジン (`metaheuristics_engine.py`, `numba_packing.py`)
*   **データ処理**: pandas, numpy, openpyxl
*   **フロントエンド**: HTML, CSS, Vanilla JavaScript

## セットアップと起動方法

### 1. 必要なライブラリのインストール

```bash
pip install -r requirements.txt
```

### 2. アプリケーションの起動

```bash
python app.py
```
デフォルトで `http://127.0.0.1:5000` でサーバーが起動します。ブラウザでアクセスしてGUIを利用できます。

## ディレクトリ構成

*   `app.py`: Flaskアプリケーションのエントリーポイント
*   `routes/`: APIルーティング（アップロード、最適化実行、Excelエクスポート等）
*   `services/`: ビジネスロジック処理群
*   `static/`: フロントエンドの静的ファイル（HTML, JS, CSS）
*   `uploads/`: ユーザーがアップロードしたファイルの保存先
*   `vanning_engine.py` / `metaheuristics_engine.py` / `numba_packing.py`: バンニング（積載）最適化のコアアルゴリズム群
*   `models.py`: データモデル
*   `data_loader.py`: Excelデータ読み込み・パース処理
*   `simulation_assumptions.json` / `simulation_assumptions.py`: シミュレーション時の各種制約パラメータ設定
